    Edit mode

    Changes are saved to collection.json in your GitHub repository, so everyone who opens the site sees them. To edit from this device you need a GitHub token:

    1. Open github.com/settings/personal-access-tokens/new
    2. Choose an expiration. Under Repository access, pick Only select repositories and select this repository.
    3. Under Permissions → Repository permissions, set Contents to Read and write.
    4. Generate the token and paste it below.

    The token is stored only in this browser. Never share it.
